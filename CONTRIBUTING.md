# Contributing to Production AI Agent Patterns

We welcome contributions from the AI engineering community!

## How to Contribute
1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/new-agent-pattern`).
3. Commit your changes (`git commit -m 'feat(pattern): add dynamic memory compaction pattern'`).
4. Push to the branch (`git push origin feature/new-agent-pattern`).
5. Open a Pull Request.

## Pattern Standards
- Provide clear architectural context and when to use vs when to avoid.
- Include executable, dependency-minimal Python code samples.
- Use GitHub Flavored Markdown and Mermaid diagrams where applicable.
